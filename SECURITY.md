# Security Policy

## Supported Versions

Only the latest published version receives fixes.

## Reporting a Vulnerability

Report it through GitHub's private vulnerability reporting:
**[Open a private vulnerability report](https://github.com/anilcancakir/magic_payments/security/advisories/new)**

The report stays confidential until a fix is ready. Include the affected version, the platform, and the steps to reproduce.

## Scope

This policy covers the `magic_payments` package: the `Payments` facade and `PaymentsManager`, the web and store billing contracts with their drivers, the entitlement and checkout models, and the `payments:*` commands. Issues in `purchases_flutter`, `magic`, `dowel`, the app stores and the Flutter SDK belong to their maintainers.
